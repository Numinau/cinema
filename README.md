# Cinema
Mini-Projet Cinéma - Dinara & Aloïs de SUPINFO
Dépôt : https://github.com/Numinau/cinema

## Manuel :
   1. Installer les dépendances : npm install
   2. Copier le fichier .env.example et le renommer en .env
   3. Dans .env, mettre une clé OMDb après VITE_OMDB_KEY=
   4. Lancer le site : npm start, puis ouvrir http://localhost:5173
